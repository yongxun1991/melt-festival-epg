# MELT Festival EPG 2026

Mobile-friendly Electronic Program Guide for **MELT Festival**  
**21 November 2026** · Melt Livehouse @ Cloud 11, Bangkok

## 如何查看

1. 直接開啟這個 repo 的 `index.html`（GitHub 會顯示原始碼）
2. 或啟用 GitHub Pages：
   - 到 repo Settings → Pages
   - Source: Deploy from a branch
   - Branch: main / (root)
   - 儲存後約 1-2 分鐘，即可在以下網址查看：
   https://yongxun1991.github.io/melt-festival-epg/

## 功能
- 時序總覽
- 四個舞台獨立檢視
- 票務與交通資訊
- 深色手機優先設計
